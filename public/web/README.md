# WebEyeTrack BlazeGaze model

These TensorFlow.js assets are required by `webeyetrack@0.0.2`, whose Worker
loads `/web/model.json` and its relative weight shard from the application
origin.

- Source repository: https://github.com/RedForestAI/WebEyeTrack
- Source commit: `75fbd2f5f784f2eb3a39675a8dcbf1b01c697f1c`
- Source path: `js/examples/minimal-example/public/web/`
- Files: `model.json`, `group1-shard1of1.bin`
- Model manifest: Keras 2.11.0 / TensorFlow.js Converter 3.21.0
- Upstream code license: MIT, preserved in the upstream repository

No separate license file for the model artifacts was observed. Redistribution
of these assets therefore requires a separate licensing review before product
distribution.
